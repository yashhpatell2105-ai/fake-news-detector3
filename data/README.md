# Dataset Directory

Place your dataset files here:

## Files to Place:
- `Fake.csv` - Fake news articles
- `True.csv` - Real news articles

## Quick Copy Commands:

```powershell
# Navigate to this folder
cd C:\fake-news-detector

# Copy your dataset files here (replace with your actual file paths)
copy "C:\Users\minec\Downloads\Fake.csv" "data\"
copy "C:\Users\minec\Downloads\True.csv" "data\"
```
